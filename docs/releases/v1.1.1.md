# ETHYLNET Orange Pi One v1.1.1 Stable

## Boot Stability Rollback

This release rolls back the v1.1.0 runtime License Patch after a
real Orange Pi One boot regression was reported.

v1.1.1 restores the previously working firmware/runtime baseline.

### Changes from v1.1.0

- Rolled back the v1.1.0 License Patch runtime
- Restored the previous booting /soft/index.o
- Restored the previous candidate2 shim behavior
- No new theme patch included
- No new license-limit patch included
- Local SSH/Dropbear remains preserved
- Existing remote-access removal remains preserved

### Status

This is the recommended stable recovery release while the v1.1.0
boot regression is investigated separately.
