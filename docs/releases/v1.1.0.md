# ETHYLNET Orange Pi One v1.1.0 Stable

> [!WARNING]
> v1.1.0 has been superseded by v1.1.1 because a boot regression was
> reported during real Orange Pi One testing. Use v1.1.1 instead.


## License Patch

This stable release includes the ETHYLNET **License Patch** and
runtime entitlement-policy update.

### License / Entitlement Information

- Level: **4**
- HotSpot maximum: **1000**
- PPPoE maximum: **1000**
- Vendo maximum: **1000**
- eLoad: **Enabled**
- Movie: **Enabled**
- License expiration: **Lifetime**
- License Info serial display:
  **OPI-[last 10 characters of the actual device serial]**
- Original hardware serial identity remains preserved for backend and
  provider communication.

### License Patch Behavior

The runtime license policy is normalized locally to the ETHYLNET
entitlement configuration.

The patch includes:

- Level 4 entitlement policy
- 1000 HotSpot capacity
- 1000 PPPoE capacity
- 1000 Vendo capacity
- Movie feature enabled
- eLoad feature enabled
- Lifetime license status
- Original device serial preserved internally
- ETHYLNET-formatted serial used only for License Info display
- Existing eLoad provider/API credential flow preserved

### Security / Remote Access

- Vendor ngrok startup link removed
- Vendor ZeroTier startup link removed
- Local Dropbear/SSH retained
- Dropbear configuration unchanged from the original firmware
- Dropbear init script unchanged from the original firmware
- Dropbear startup link preserved

### Firmware Integrity Verification

Verified against the original firmware:

- Image size preserved
- Partition table preserved
- Raw MBR preserved
- Boot/prefix bytes preserved
- Boot partition byte-identical
- Original 815-byte firmware trailer preserved
- Final root filesystem delta set audited
- Final `/soft/index.o` verified
- Deterministic gzip package verified
- Decompressed package reproduces the exact verified raw image
