# Privacy Policy

This repository itself does not intentionally contain customer credentials,
private user databases, payment credentials, device secrets, or personally
identifiable production data.

Contributors must not commit:

- customer databases;
- access tokens;
- passwords;
- private SSH keys;
- payment credentials;
- API secrets;
- production logs containing personal data.

Operators of deployed firmware are responsible for their own privacy,
retention, access-control, and legal-compliance obligations.
