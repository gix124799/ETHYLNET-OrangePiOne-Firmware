# Security Policy

## Supported Version

Security fixes are currently provided for the latest stable ETHYLNET Orange Pi One firmware release.

## Reporting a Vulnerability

Do not publish an exploitable security vulnerability in a public GitHub issue.

Use GitHub private vulnerability reporting when available, or contact the project owner privately.

Please include:

- affected version;
- component or file involved;
- reproduction details;
- security impact;
- relevant logs;
- suggested mitigation, if known.

## Security Principles

The project aims to:

- preserve local administrative recovery;
- protect local SSH access;
- minimize unnecessary external remote-control paths;
- preserve required application services;
- document intentional firmware modifications;
- verify release integrity using cryptographic hashes.

A security report does not guarantee a particular remediation timeline.
